CSS Positioning

The CSS Positioning module defines how elements are positioned in a document. It includes properties such as static, relative, absolute, fixed, and sticky positioning.

The types of positioning

  1. Static Positioning: This is the default positioning for all HTML elements. Elements are positioned according to the normal flow of the document.
  2. Relative Positioning: An element with relative positioning is positioned relative to its normal position. You can use the top, right, bottom, and left properties to adjust its position.
  3. Absolute Positioning: An element with absolute positioning is removed from the normal document flow and positioned relative to its nearest positioned ancestor (an ancestor with a position other than static). If there is no such ancestor, it is positioned relative to the initial containing block (usually the viewport).
  4. Fixed Positioning: An element with fixed positioning is removed from the normal document flow and positioned relative to the viewport. It stays in the same position even when the page is scrolled.
  5. Sticky Positioning: An element with sticky positioning toggles between relative and fixed positioning based on the user's scroll position. It behaves like a relatively positioned element until it reaches a specified threshold, at which point it becomes fixed.
